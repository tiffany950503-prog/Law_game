# 國民法官：庭審日誌

國民法官模擬遊戲（手機直式）。玩家先做「心理側寫前測」，再審理多日庭期的案件，練習交互詰問、筆記與評議。

## 內容
- **心理側寫前測（9 關）**：改編自法律心理學研究的小遊戲，包括錨定擲骰（Englich 等, 2006）、車禍用詞與記憶（Loftus & Palmer, 1974）、從眾線段（Asch, 1956）、故事模型（Pennington & Hastie, 1992）、陪審員偏見量表面向（Kassin & Wrightsman, 1983）、公正世界信念（Lerner, 1980）、認知反思（Frederick, 2005）、專家頭銜（Cooper 等, 1996）。結果會變成審判中的個人化提醒，並模擬選任程序中檢辯雙方的視角。
- **五個案件**（每案 3 個庭期，加上評議日與宣判日）：
  - 《王鈞殺人未遂案》：殺意 vs. 傷害（改編自司法院模擬劇本）
  - 《沈雅雯殺夫案》：外遇、他殺 vs. 自殺
  - 《青山村土地案》：財團收購土地、共謀與傷害致死
  - 《三百萬欠條案》：擄人勒贖 vs. 討債
  - 《漁港標案收賄案》：賄賂 vs. 借款、統計證據
- **法庭互動**：開審陳述、主詰問／反詰問、異議（玩家先猜裁定）、鑑定人、雙方聲請傳喚新證人（庭期表即時更新）、被告陳述與緘默權、結辯、科刑辯論。
- **筆記教室（做中學）**：事實／推論／意見分類 → 挑選好筆記 → 自己寫 → 找矛盾 → 排時間線；評議時從筆記挑理由。
- **休庭人性觀察**：分析檢辯策略與每位證人的利益（可能強調什麼、淡化什麼）。
- **庭期之間**：國民法官義務情境（保密、不接觸報導、不自行調查等）。
- **評議**：先寫再聽、2/3 有罪門檻、量刑錨定指數、心證軌跡圖。

## 建置
原始碼在 `src/`，執行下列指令產生 `index.html`：

```
python3 build.py
```

`src/scenes.json` 是原 Demo 的插圖，`src/audio.js` 是原 Demo 的音樂、音效與語音模組。
